Synack is a crowdsourced security testing platform that pairs the Synack Red Team — a global community of vetted security researchers — with AI-enabled attack-surface discovery to deliver continuous penetration testing, vulnerability management, and compliance-grade assessments. The Synack Enterprise API exposes assessments, assets, asset discovery (seed groups and seeds), vulnerabilities and suspected vulnerabilities, missions and campaigns, tagging, tests, users, and streaming analytics across nine REST services, secured with OAuth2 scopes and JWT bearer tokens.

**Areas:** Company · Security · Penetration Testing · Vulnerability Management · Attack Surface Management · Crowdsourced Security · Compliance

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Synack: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
